GoclashZ создан в знак протеста против чрезмерной раздутости современного десктопного ПО. Отказавшись от архитектуры Electron, проект использует системный параллелизм языка Go и нативный рендеринг Wails, снижая потребление оперативной памяти и ресурсов процессора до физического минимума. В визуальном плане проект строго придерживается высококонтрастной монохромной эстетики без лишних градиентов и украшательств.

## Основные возможности

### Сетевой контроль и перехват трафика

* **Архитектура изоляции привилегий через Helper**: Отдельная локальная фоновая служба (Named Pipe IPC) безопасно выполняет привилегированные операции (режим TUN, исключения UWP). Основной интерфейс всегда работает с правами обычного пользователя без всплывающих окон UAC.
* **Интеллектуальный режим TUN**: Автоматическая установка и самовосстановление драйвера Wintun для прозрачного проксирования всего системного трафика.
* **Исключения UWP**: Разблокировка локальной сети для приложений Windows Store / UWP в один клик.
* **Общий доступ по LAN**: Раздача прокси в локальной сети, отдельный порт SOCKS5, аутентификация и списки доступа IP (ACL).
* **Системный прокси**: Мгновенное переключение системного прокси Windows на уровне реестра.

### Интернационализация и поддержка языков (i18n)

* **Собственный реактивный движок без внешних библиотек**: Мгновенное переключение языка на базе Vue 3 без перезагрузки и мерцания интерфейса.
* **8 поддерживаемых языков**: Упрощенный китайский, традиционный китайский (Тайвань), традиционный китайский (Гонконг), английский, японский, русский, французский, немецкий со 100% совпадением ключей перевода.
* **Адаптивная защита верстки**: Автоматическое расширение боковой панели до 205px для длинных слов, нативные шрифты Windows для кириллицы и CJK.
* **Синхронизация системного трея**: Меню трея Windows автоматически переводится на выбранный язык.

### Производительность и управление состоянием

* **Определение маршрута и dual-stack**: Проверка исходящего IP через внутренний порт прокси для исключения ложного прямого трафика в TUN. Параллельная проверка IPv4/IPv6.
* **ControlCoordinator**: Исключение гонок состояний и конфликтов между UI, треем и фоновыми службами.
* **Надежный автозапуск через реестр**: Переход с нестабильного планировщика задач COM на нативный ключ реестра `HKCU\Run`.

## Установка и запуск

Загрузите последнюю версию со страницы [Releases](https://github.com/Zzz-IT/GoclashZ/releases).

## Для разработчиков

```bash
# Запуск dev-сервера с горячей перезагрузкой
wails dev

# Сборка релизного файла для Windows
wails build
```
